# Расписание: сайт для GitHub Pages

Файлы в этой папке:
- `index.html` - страница с расписанием (главная)
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` - нужны, чтобы сайт можно было установить на телефон как приложение

## Как выложить на GitHub Pages

1. Зайдите на github.com и войдите в аккаунт (или зарегистрируйтесь).
2. Нажмите **+** справа вверху и выберите **New repository**.
3. Имя, например, `raspisanie`. Выберите **Public** и нажмите **Create repository**.
4. На странице репозитория нажмите **uploading an existing file**.
5. Распакуйте zip и перетащите **файлы из папки** (не саму папку), чтобы `index.html` лежал в корне репозитория. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В разделе Source выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
7. Через 1-2 минуты сайт откроется по адресу:
   `https://ВАШ-ЛОГИН.github.io/raspisanie/`

Названия пунктов на GitHub могут немного отличаться.

## Установка на телефон (Android, Chrome)

Откройте адрес сайта, нажмите **⋮** и выберите **Установить приложение** или **Добавить на главный экран**. Иконка появится на рабочем столе.

## Как обновлять

- Расписание на неделю вставляйте прямо на странице в окне «Обновить расписание». Оно хранится в телефоне.
- Чтобы изменить расписание, зашитое в файл, откройте `index.html` в репозитории, нажмите значок карандаша, поправьте и нажмите **Commit changes**.

## Важно

Сайт на GitHub Pages открыт всем, у кого есть ссылка. Не кладите в файлы пароли и личные данные. Расписание из файла (предметы, кабинеты, преподаватели) тоже будет видно по ссылке.
